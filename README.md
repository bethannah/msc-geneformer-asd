# MSc Geneformer ASD Analysis
Code associated with my MSC Bioinformatics project:
> **Deciphering the molecular links between autism and its comorbid conditions with AI-assisted exploration of transcriptomic data**

---
## Project Overview
This repository contains the scripts used to analyse single-cell transcriptomic data from valproic acid (VPA)-exposed cerebral organoids dataset using **Geneformer**.
The project investigates transcriptomic effects associated with autism spectrum disorder (ASD), with a focus on *in silico* gene perturbation and comparison of ASD genes with matched non-ASD genes.
The workflow includes data preprocessing, Geneformer tokenization and cell embedding extraction, gene selection, *in silico* perturbation, statistical analysis, phenotypic annotation and visualisation.

## Analysis Workflow
1. Data preprocessing
The original single-cell .h5ad dataset was prepared for Geneformer analysis using vpa_geneformer_ready.py. Raw count data were retained and the required gene identifiers and cell metadata were prepared for downstream Geneformer processing.
The prepared dataset was checked using h5ad_file_inspection.py

2. Geneformer tokenization and embeddings
The prepared single-cell dataset was tokenised using tokenization.py with Geneformer.
Geneformer cell embeddings were extracted and used to examine the representation of experimental condition and cell subtype within the learned embedding space.
These workflows were adapted from the tutorial provided by the Geneformer package, with the scripts therefore retaining the underlying Geneformer framework while incorporating dataset-specific steps.
Computationally intensive Geneformer stages were executed on the University Linux compute server using the accompaning .csh job scripts.

3. ASD Gene Selection
ASD-associated genes were identified from the SFARI Gene database
Genes were screened for sufficient detection within the control cells before selection of the final ASD gene set. The relevant scripts used:
    asd_gene_screening.py
    select_asd_genes.py

4. Matched Non-ASD Gene selection
A candidate pool of non-ASD genes were generated after excluding ASD-associated and predefined VPA reference genes. These VPA reference genes were excluded to avoid including genes already linked to the VPA exposure model within the control group. Non-ASD genes were then matched to the selected ASD genes according to transcriptomic detection characteristics. 
Relevant scripts:
    non_asd_gene_screening.py
    match_genes.py
    create_gene_panel.py

5. In silico perturbation
Geneformer *in silico* perturbation performed using batch_in_silico_perturbation.py. This was adapted from the original Geneformer script's functionality to allow for perturbation to be automated.
Perturbations were evaluated using changes in cell-state embeddings relative to the predefined target state.
Per-gene perturbation outputs generated by Geneformer are not included in this repository due to the number and size of them.

6. Statistical analysis
Perturbation outputs were combined using combined_stats.py.
Downstream summary statistics and gene rankings were generated using analyse_results.py
ASD and matched non-ASD perturbation effects were compared and visualised using:
    plot_group_comparison.py
    plot_ranked_results.py


7. HPO phenotypic and comorbidity annotation
ASD-associated genes were annotated using Human Phenotype Ontology (HPO) phenotype-to-gene associations to explore known links between the perturbed genes and co-occurring neurodevelopmental and clinical phenotypes using the following scripts:
    annotate_comorbidities.py
    comorbidity_analysis.py
The workflow was used to identify phenotype associations and group these into broader categories relevant to ASD comorbidity. SFARI syndromic status was also incorporated for exploratory comparison.

## Data and large intermediate files
Large transcriptomic files and Geneformer intermediate files are not included in this repository due to size.
This includes:
    Original and processed .h5ad files for Geneformer processing
    Tokenised Geneformer dataset
    Geneformer model set-up files
    Pickle files
    Individual per-gene perturbation output directories
    SLURM output & error logs

The repository contains the scripts to generate these outputs and selected final summary results. Some scripts associated with server-based computation and analysis retain paths corresponding to the original compute environment and require path modification if they were to be reproduced.


## Reference Data
The analysis uses:
    ASD-associated gene information obtained from the SFARI gene database (version July 12 2026)
    Phenotype-to-gene annotations obtained from the Human Phenotype Ontology (HPO)


## Software and computing environment
Local analysis was primarily performed using Python version 3.13.1 with packages including:
    Scanpy
    AnnData
    pandas
    NumPy
    SciPy
    Matplotlib

Geneformer analysis was performed on a University Linux compute server using:
-Python 3.12
-Geneformer using the V1 model configuration
-SLURM for job submission and management
